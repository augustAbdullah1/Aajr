# آجر - تطبيق الذكر والأدعية المتطور

## 🌟 وصف التطبيق
تطبيق آجر هو تطبيق شامل للذكر والأدعية والقرآن الكريم ومواقيت الصلاة، مصمم بتقنية PWA للعمل كتطبيق محلي على الهاتف.

## ✨ الميزات الرئيسية

### 📿 عداد الذكر المتطور
- عداد ذكي مع حفظ تلقائي
- الوضع الهادئ للتركيز
- إحصائيات مفصلة
- أهداف يومية

### 🕌 مواقيت الصلاة
- مواقيت دقيقة لجميع الدول
- توقيت 12 ساعة
- تحديد الموقع التلقائي
- بوصلة القبلة مع GPS

### 📖 القرآن الكريم
- القرآن كامل مع جميع السور
- قراء متعددين (عبد الباسط، مشاري العفاسي، السديس)
- تشغيل الصوت
- واجهة جميلة للقراءة

### 🙏 الأدعية المأثورة
- مجموعة شاملة من الأدعية
- إمكانية النسخ
- تصنيف الأدعية
- واجهة سهلة الاستخدام

### 📊 إحصائيات متقدمة
- تتبع التقدم اليومي
- الأيام المتتالية
- الإحصائيات الإجمالية
- رسوم بيانية تفاعلية

### 🔔 الإشعارات المتطورة
- إشعارات مخصصة
- تذكيرات ذكية
- دعم الاهتزاز
- إشعارات المتصفح

## 🛠️ التقنيات المستخدمة

- **HTML5** - هيكل التطبيق
- **CSS3** - التصميم والأنيميشن
- **JavaScript ES6+** - الوظائف التفاعلية
- **PWA** - تطبيق ويب تقدمي
- **Service Worker** - العمل بدون إنترنت
- **Web APIs** - GPS، الإشعارات، التخزين

## 🌐 APIs المستخدمة

- **Aladhan API** - مواقيت الصلاة
- **AlQuran Cloud API** - القرآن الكريم
- **MP3Quran API** - تلاوات القرآن
- **Geolocation API** - تحديد الموقع

## 📱 تثبيت التطبيق

### على الهاتف:
1. افتح التطبيق في المتصفح
2. اضغط على "إضافة للشاشة الرئيسية"
3. التطبيق سيعمل كتطبيق محلي

### على الكمبيوتر:
1. افتح الرابط في المتصفح
2. التطبيق يعمل مباشرة
